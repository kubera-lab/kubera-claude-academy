# KUBERA AI START

Бесплатная школа искусственного интеллекта для обычных людей. / A free AI school for everyday people.

- Уроки по 7–8 минут: ситуация из жизни или работы → суть (до 4 тезисов) → разбор слабого и сильного запроса → практика → 4 вопроса на понимание → главное из урока.
- Взрослая, серьёзная подача: реальные рабочие примеры, без детских историй и игровых украшений.
- Без программирования, без регистрации, без платных API.
- Русский и английский. Удобно с телефона.
- Каждый неправильный ответ объясняется. Ошибки попадают в «Повторить ошибки».
- Прогресс хранится только в браузере (localStorage). Если браузер его запрещает, сайт всё равно работает.

Существующая KUBERA Claude Academy остаётся для тех, кто хочет программирование, SQL, GIS и AI-агентов. KUBERA AI START учит, как обычному человеку правильно работать с ИИ.

## Запуск

Сборка не нужна, это обычные HTML, CSS и JavaScript.

```bash
npm start            # или: python3 -m http.server 8080
# открыть http://localhost:8080
```

Открыть `index.html` двойным щелчком нельзя: браузер не загружает модули с `file://`. Нужен любой локальный сервер.

## Проверки

```bash
npm test             # 23 проверки логики и содержания уроков, включая Лабораторию KUBERA (Node 18+)
npm run e2e          # браузер: компьютер 1280px и iPhone 13, нужен playwright
```

`npm test` проверяет, что в каждом уроке есть все части на двух языках, у каждого варианта ответа есть объяснение, правильные ответы стоят на разных местах, уроки короткие. `npm run e2e` проходит весь курс как ученик: ошибается, повторяет ошибку, перезагружает страницу, получает значок, переключает язык, проверяет отсутствие горизонтальной прокрутки, размер кнопок и ошибок в консоли.

## Как устроено

```
index.html          оболочка страницы
css/style.css       светлая и тёмная тема, крупный текст, кнопки от 44px
js/app.js           экраны: главная, уроки курса, урок по шагам, повтор ошибок
js/logic.js         логика без DOM: проверка ответов, прогресс, симулятор
js/i18n.js          надписи интерфейса RU/EN
data/courses.js     список 8 курсов
data/course1.js     весь текст курса 1 (RU и EN) и ключи ответов
tests/              автотесты
docs/PROGRAM.md     программа 8 курсов
SOURCES.md          откуда взяты идеи
```

### Как добавить урок

Скопируйте объект урока в `data/course1.js` (или новый файл курса), заполните `ru` и `en`, укажите в `key` номера правильных ответов (с 0). Объяснение правильного ответа начинается со «Верно» / «Correct». Запустите `npm test`: он покажет, чего не хватает.

## Честность симуляций

«Лаборатория запросов» — заранее написанные ответы, а не настоящая нейросеть. На экране это сказано прямо. Все будущие симуляторы делаются так же и маркируются так же.
