# Лаборатория KUBERA

Отдельный раздел школы KUBERA AI START. Цель: владелец KUBERA понимает технологии своих проектов, руководит разработкой, проверяет результаты и может применять знания на других предприятиях.

Принцип: **изучаем → проверяем → применяем → создаём собственный продукт.** Каждая выполненная техническая задача в проектах KUBERA становится учебным материалом.

## Как устроен урок (6 шагов, 8 минут)

1. **Ситуация** — реальная задача из проекта KUBERA в обезличенном виде (учебная мебельная фабрика, помощник Замбала), на учебных данных.
2. **Суть** — теория простым русским языком, до 4 тезисов.
3. **Термины** — английский термин, перевод, произношение русскими буквами.
4. **Разбор** — как неправильно и как правильно.
5. **Задание** — небольшая практика самому, плюс готовый запрос для чат-бота.
6. **Проверка** — 4 вопроса, объяснение каждого варианта, ошибки уходят в «Повторить ошибки».

Результат обучения сохраняется в браузере: пройденные уроки, счёт, направления и личный словарь терминов («Мои результаты» на странице курса).

## Правила содержания

- Только проверенные факты из отчётов и кода проектов. Цены и лимиты — с датой проверки.
- Только учебные (вымышленные) данные. Никаких настоящих данных предприятий, паролей, кодов, адресов.
- Не придумывать правила и стандарты предприятий (например, внутренние правила предприятия-клиента).
- GeoAI изучается только по существующим материалам, без возобновления разработки.
- Без платных сервисов.
